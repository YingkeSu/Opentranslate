# 验收清单（Acceptance Checklist）

## A. 功能验收

- [ ] 划词触发翻译可用
- [ ] 右键菜单触发翻译可用
- [ ] 快捷键触发翻译可用
- [ ] 流式增量输出可见
- [ ] 用户取消后请求立即停止
- [ ] Provider fallback 生效
- [ ] 设置页配置可保存并实时生效

## B. 性能验收

- [ ] `TTFT P50 <= 800ms`
- [ ] `TTFT P95 <= 1800ms`
- [ ] 150-300 字总时延 `P50 <= 3.5s`
- [ ] 缓存命中首字时间显著优于未命中
- [ ] 无明显 UI 卡顿或闪烁

## C. 稳定性验收

- [ ] 429 场景可重试且不雪崩
- [ ] Provider 不可用时可自动切换
- [ ] 多 tab 并发场景稳定
- [ ] MV3 worker 休眠后可恢复核心流程

## D. 安全与合规验收

- [ ] API Key 不暴露到 content-script
- [ ] 权限最小化并与功能一致
- [ ] 消息 schema 校验覆盖关键入口
- [ ] 日志不含敏感明文文本
- [ ] 隐私说明与用户告知完整

## E. 发布验收

- [ ] 回归测试通过
- [ ] 版本号与 changelog 已更新
- [ ] 商店素材与文案齐备
- [ ] 回滚方案已验证
